# EpicSync — release

Qui ci sono solo gli installatori di EpicSync per Windows, non il codice.

EpicSync installato controlla questa pagina da solo e propone gli
aggiornamenti dal menu **Aiuto → Cerca aggiornamenti**: non serve scaricare
niente a mano.

Per una prima installazione: aprire la release più recente in
[Releases](https://github.com/Terronologo/EpicSync-releases/releases) e
scaricare `EpicSync-Setup_v<versione>.exe`. Accanto c'è il file `.sha256`
con l'impronta dell'installatore.
